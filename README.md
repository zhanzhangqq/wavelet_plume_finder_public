# Wavelet Plume Finder

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.21286248.svg)](https://doi.org/10.5281/zenodo.21286248)

This repository contains the code for automated point-source methane plume masking based on wavelet transform image processing. The methodology is described in:

> Zhang, Z., et al. (2026). *Automatic methane plume masking based on wavelet transform image processing: application to MethaneAIR and MethaneSAT data*. EGUsphere [preprint]. https://doi.org/10.5194/egusphere-2026-141

## Overview

The Wavelet Plume Finder identifies methane plumes from methane concentration images by separating plume signals from background variations using wavelet transform techniques.

Given a methane concentration image, the algorithm first applies wavelet decomposition to extract high-frequency components. These high-frequency components are then removed from the original image through inverse wavelet reconstruction, assuming that high-frequency signals primarily represent background noise and image artifacts. The resulting image is referred to as the "denoised image" and provides an improved representation of methane enhancements.

Methane plume masks are subsequently generated by identifying high-value pixels in the denoised image. The detected masks are further refined through three filtering steps:

1. **Hotspot filter** – removes isolated enhancements inconsistent with plume characteristics.
2. **Wind direction filter** – evaluates plume alignment with local wind direction.
3. **Shape filter** – removes detections with shapes inconsistent with methane plumes.

The final plume masks are those that pass all filtering criteria.
